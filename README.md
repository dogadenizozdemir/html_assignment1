# Astrology & Tarot - HTML5 Assignment

## Theme
The theme of this project is a fictional advisory service focusing on traditional Horary astrology (based on William Lilly's techniques) and Tarot readings. The goal is to present astrological information and services cleanly using semantic HTML.

## File Organization
The project consists of 4 main HTML files and an assets folder:
* `index.html`: The homepage containing the main articles and introductory images.
* `about.html`: Details about the website's purpose, utilizing various semantic tags (`<figure>`, `<mark>`, `<details>`, `<blockquote>`, etc.).
* `services.html`: Contains a structured table listing the reading services and prices.
* `contact.html`: Includes a fully functional form for users to request a reading.
* `assets/`: A folder containing all the images (`.jpg` files) used across the website.
* `README.md`: This file, explaining the project structure and details.

## Challenges Faced
The main challenge was structuring the pages properly without relying on CSS for layout and design. Ensuring that semantic tags (like `<aside>` and `<time>`) were used logically in the `about.html` page required careful planning. Additionally, building the table with `<thead>`, `<tbody>`, and `<tfoot>` sections, as well as properly structuring the form inputs, required strong attention to detail.
